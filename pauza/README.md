# ПАУЗА — серия 1

Анимированная серия с главным героем Эльмиром, построенная по озвучке.

- `pauza.mp4` — готовое видео (1920×1080, 30 к/с, 70 с, голос + звуковые эффекты, субтитры).
- `index.html` — интерактивный плеер (та же анимация рисуется в реальном времени на canvas, субтитры можно выключить).
- `anim.js` — все сцены, переходы и тайминги (каждая фраза привязана к своей секунде в аудио).
- `sprites/` — Эльмир, вырезанный из листа персонажа (тело, походка, 8 эмоций).
- `pauza_audio.mp3` — сведённая дорожка: голос + синтезированные эффекты (часы, вибрация, заморозка, сердцебиение, шаг).

Перерендер видео: открыть `index.html?render=1` и вызывать `renderAt(t)` покадрово (так сделан `pauza.mp4`).
