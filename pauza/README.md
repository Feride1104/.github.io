# ПАУЗА — серия 1

Анимированная серия с главным героем — Ильмиром Ильдаровичем, построенная по озвучке.

- `pauza_vertical.mp4` — основное видео 9:16 (1080×1920, 30 к/с, 70 с) с кинетическими субтитрами:
  крупные и мелкие слова чередуются, строки меняют выравнивание, акценты выделены красным и глитч-шрифтом.
- `pauza.mp4` — горизонтальная версия 16:9 (1920×1080) с обычными субтитрами.
- `index.html` — интерактивный плеер (по умолчанию 9:16, горизонтальный — `index.html?format=landscape`).
- `anim.js` — все сцены, переходы и тайминги (каждая фраза привязана к своей секунде в аудио),
  массив `KSUBS` — текст и разметка субтитров: `*слово*` — крупно, `!слово!` — крупно красным, `~слово~` — глитч.
- `sprites/` — Ильмир, вырезанный из листа персонажа (тело, походка, 8 эмоций).
- `pauza_audio.mp3` — сведённая дорожка: голос + синтезированные эффекты.

Перерендер: открыть `index.html?render=1` (или `?render=1&format=landscape`) и вызывать `renderAt(t)` покадрово.

## Серия 2

- `pauza2_vertical.mp4` — 9:16 (1080×1920, 76 с), `pauza2.mp4` — 16:9.
- `seria2.html` — плеер второй серии (`?format=landscape` — горизонтальный).
- `anim2.js` — сцены второй серии: камеры наблюдения, кабинеты, таймлапс дня, второе нажатие,
  постаревший двойник (`sprites/old_front.webp`, `sprites/old_body.webp`), записка «НЕ НАЖИМАЙ ТРЕТИЙ РАЗ», распад на частицы.
- `pauza2_audio.mp3` — голос + звуковые эффекты второй серии.

Рендер второй серии нужно делать через локальный веб-сервер (`python3 -m http.server`), а не `file://`: эффекту распада нужен доступ к пикселям спрайта.

## Серия 3 — финал первого сезона

- `pauza3_vertical.mp4` — 9:16 (1080×1920, 88 с), `pauza3.mp4` — 16:9.
- `seria3.html` — плеер третьей серии, `anim3.js` — сцены: распад двойника (сначала руки, потом лицо),
  вторая записка, «пустота» с застывшими часами, удаление приложения, ночное сообщение
  «ПОСЛЕДНЯЯ ОСТАНОВКА ИСПОЛЬЗОВАНА», двойник в дверях (`sprites/old_smile.webp`).
- После «Он улыбался» — две секунды абсолютной тишины (80.1–82.1 с), затем чёрный экран и «КОНЕЦ ПЕРВОГО СЕЗОНА».
- `pauza3_audio.mp3` — голос + звуковые эффекты.
